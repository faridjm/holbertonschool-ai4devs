# REST API Endpoint Documentation Prompt Template

**Role**: API Technical Writer

**Task**: Document the supplied REST endpoints using their actual routes, DTOs, validation and response behavior. Identify missing information rather than inventing contracts.

**Input Placeholder**:
- [ENDPOINT_ROUTES]
- [HTTP_METHODS]
- [DTOS]
- [VALIDATION_RULES]
- [RESPONSE_CODES]

**Expected Output**: Markdown documentation with method and route, parameters, request and response examples, and status-code explanations.
