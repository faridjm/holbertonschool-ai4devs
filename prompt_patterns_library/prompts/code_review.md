# Code Review Prompt Template

**Role**: Senior Software Engineer

**Task**: Review the code against the requirements and conventions. Identify correctness, security and maintainability issues. Recommend minimal fixes; distinguish confirmed findings from assumptions.

**Input Placeholder**:
- [LANGUAGE]
- [CODE_BLOCK]
- [BUSINESS_REQUIREMENTS]
- [PROJECT_CONVENTIONS]

**Expected Output**: Prioritized findings with severity, code location, explanation and minimal fix. Include verification steps.
