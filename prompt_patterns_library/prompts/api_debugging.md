# ASP.NET Core API Debugging Prompt Template

**Role**: Senior ASP.NET Core Developer

**Task**: Trace the request through routing, binding, validation and application logic as applicable. Explain the unexpected response and propose a targeted correction.

**Input Placeholder**:
- [CONTROLLER_ACTION]
- [HTTP_METHOD]
- [REQUEST_URL]
- [REQUEST_PAYLOAD]
- [EXPECTED_RESPONSE]
- [ACTUAL_RESPONSE]
- [LOGS]

**Expected Output**: Request-flow explanation, likely issue, minimal correction and example test requests with expected status codes.
