# XML Documentation for C# Methods Prompt Template

**Role**: C# Technical Documentation Engineer

**Task**: Write accurate XML documentation comments for the supplied public methods. Describe actual behavior and avoid inventing guarantees or exceptions.

**Input Placeholder**:
- [METHOD_SIGNATURES]
- [IMPLEMENTATIONS]
- [PARAMETER_MEANINGS]
- [EXPECTED_BEHAVIOR]

**Expected Output**: C# code with XML summary, param, returns and exception tags where applicable.
