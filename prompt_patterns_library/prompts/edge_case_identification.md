# Edge Case Identification Prompt Template

**Role**: Software Quality Engineer

**Task**: Identify realistic boundary conditions, invalid inputs and regression risks based on the requirements. Prioritize by impact and distinguish defined behavior from unresolved business decisions.

**Input Placeholder**:
- [FEATURE_REQUIREMENTS]
- [VALIDATION_RULES]
- [RELEVANT_CODE]

**Expected Output**: Prioritized edge-case table with scenario, expected result, rationale and suggested test. Flag unspecified behavior.
